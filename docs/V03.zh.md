# duorou v0.3.0 — 候选召回实验

设计原则：保留同一 SQLite 数据模型、原始证据 ID、作用域门禁和已有 MCP 服务，不改旧基线。新增两个很小的算子：RRF 排名融合和可选的同组去冗余。新增一个实验索引 `fts_enriched_context`，为每个叶子记录建立当前内容与同一来源会话前后各一回合的检索键。查询两个索引各取最多 100 条候选，RRF 排序，返回实际叶子 ID。没有把整个会话算成证据，没有读取 gold 或题型，运行时不依赖 LoCoMo ID 格式。权限沿用已有检查；全局 FTS 统计隔离、实时更新、认证与生产部署仍未完成。

## 已运行

- 28 个单元/约束/适配测试全部通过（`reports/v0.3-tests.txt`）。
- 旧 LoCoMo 1,527 题、三个固定 top20 结果集合的真实排序回放：`reports/replay-v0.3.json`。RRF 参数固定为 60；去冗余惩罚 0.1。该集已参与开发诊断，不是独立测试集。
- 新上下文索引及直接评测脚本用合成小样例执行；未重新跑公开原文数据。

| 回放方法 | Recall@20 | AllHit@20 | 多跳 AllHit@20 |
|---|---:|---:|---:|
| BM25 增强 | 62.03% | 56.84% | 14.75% |
| FTS 增强 | 63.77% | 57.96% | 13.31% |
| FTS 邻居 | 69.33% | 63.85% | 11.51% |
| RRF 两个直接检索 | 63.55% | 58.28% | 14.75% |
| RRF 三路 | 67.34% | 61.82% | 14.03% |
| RRF 三路 + 会话多样性 | 64.15% | 58.68% | 14.03% |
| 三路候选全集（不受 top20 限制，非可部署排名） | 75.02% | 68.96% | 19.78% |

结论：没有一种回放融合同时超过邻居策略总体成绩和 BM25 多跳成绩；保留为实验，不切换默认值。候选全集上界显示应优先扩展候选，而非只重排。新增上下文索引尚无公开集质量数字。

## 复现

```sh
python -m unittest discover -s tests -v
python -m benchmarks.replay reports/locomo-20261124/quality
python examples/download_locomo.py --output data/raw/locomo10.json
python -m benchmarks.compare_context --locomo data/raw/locomo10.json --output reports/context-new
```

最后一个命令比较四个方法，使用固定 SHA256 的完整公开原文；输出逐题排名、分题型指标、串行进程内时延及索引统计。不同于 MCP 压测。`benchmarks.run` 保持旧版五组历史协议不变。要测试新增 MCP 目标，可在准备相同 SQLite 库后使用 `python -m benchmarks.target --method fts_enriched_context --db PATH --port 8765 --index-report PATH`。本轮当前环境不能下载原始语料，且没有 MCP SDK，故未执行新 MCP 端到端和竞品测量。没有生成最终问答或 SOTA 成绩。

## v1.0 门槛

1. 公开原文可用后，先评测新的候选索引，只有验证提升的模块进入默认路径。固定独立测试集或新增公开数据，禁止在测试集调参。
2. 在相同预算下增量加入语义检索、带来源的结构化抽取、跨会话关系和证据选择，每次做消融。避免并列维护多套数据模型；无收益删除。
3. 同一模型、裁判、实际 token 预算下独立运行 BM25、向量 RAG、至少两套可复现同类记忆系统，报告质量、查询延迟、写入开销、失败和成本。
4. 完整摄入、更新、删除、授权和证据读取；校准压测器，验证并发及索引新鲜度。未完成以上验收不得标记为 v1.0 或宣称超越竞品。
