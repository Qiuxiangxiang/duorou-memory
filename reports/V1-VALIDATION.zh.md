# duorou 1.0.0 实现版验证记录

本轮先交付核心代码，再整体评测。以下为本轮实际执行结果，非公开 benchmark SOTA 分数。

## 功能测试

- 47 项 unittest 全部通过（28 项既有，19 项新增）。
- MCP：17 个业务工具经注册函数调用测试；执行环境缺 MCP SDK，未运行真实 stdio 握手。
- 向量/模型抽取：仅用显式测试回调验证；未使用实际模型权重。
- 公开原始数据下载失败：DNS 无法解析 raw.githubusercontent.com，容器下载亦失败。未使用旧分数冒充新版结果。

## 合成检索对照

768 条记录，392 道查询（384 道正例、8 道无结果探针），Top-5，4,096 UTF-8 正文字节预算。该 fixture 强调局部上下文，不是独立泛化测试。四组合计 1568 次查询，均无错误。

| 方法 | Recall@5 | AllHit@5 | P95 ms |
|---|---:|---:|---:|
| reference_bm25 | 79.17% | 58.33% | 0.349 |
| bm25 | 79.17% | 58.33% | 0.266 |
| enriched | 79.17% | 58.33% | 0.253 |
| hybrid | 82.29% | 64.58% | 0.391 |

## 合成压力测试

5,000 条记录，闭环并发 1/8，每档 3 次、每次 1,000 请求，共 6,000 次。直接 Python 调用，完整证据正文返回；未计 MCP 传输和模型，不是持续容量或饱和点。

| 并发 | QPS 中位数 | P95 中位数 ms | P99 最大值 ms |
|---|---:|---:|---:|
| 1 | 5516.0 | 0.217 | 0.431 |
| 8 | 6115.7 | 7.610 | 19.048 |

全部 6,000 次精确 ID 探针命中；冷启动首次查询 213.7 ms，写入后首次查询 169.4 ms（找到），删除后首次查询 174.8 ms（未找到）。

主要性能缺口是全作用域快照重建和单服务锁竞争。不能用热缓存 QPS 直接和历史 MCP P95 比较。
